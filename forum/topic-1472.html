<p align="justify">
Voici une petite explication pour les personnes n'étant pas des néophytes avec l'utilisation d'IRC.Tout d'abord je vous invite à télécharger <a href="http://www.mirc.com/get.html">mIrc</a>. Tout d'abord il faut aller dans les options d'IRC en allant dans <img src="http://eastblue.net/picture/download/tutorial/irc/12.jpg"> . Ceci ouvrira une fenêtre identique à celle ci-dessous :
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/01.jpg">
</p>
<br>
<p align="justify">
Dans la rubrique connect remplissez les champs tel que bon vous semble (les champs ont été rempli comme exemple).La seconde étape de confguration est celle concernant la reception des fichiers via mIRC. Pour cela,toujours dans la fenêtre d'option vous allez sur l'image ci-dessous :
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/03.jpg">
</p>
<p align="justify">
Vous configurez les options exactement comme celle ci-dessus,puis vous allez dans :
</p>
<br>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/04.jpg">
</p>
<p align="justify">
Le plus important là est de surtout décocher le <b>Show warning</b> qui se trouve être coché par défaut .Ceci permet entre autre d'éviter d'avoir une fenêtre qui vous demande d'accepter un transfert à chaque fois que vous essayerez de télécharger quelque chose.<br>
Si jamais vous désirez filtrer des extensions vous allez dans :
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/05.jpg">
</p>
<p align="justify">
Vous choisissez <b>accept only</b> ,ceci vous permettra de choisir ensuite seulement les extensions que vous accepterez à télécharger(vous pouvez en rajouter par vous même en mettant *.extension ,si vous voulez rajoutez les fichiers.rar vous mettez *.rar).<br><br>
Sinon ,une fois tout ceci fait ,il faut que vous choisissiez le bon server auquel vous devez vous connecter.
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/02.jpg">
</p>
<p align="justify">
Dans notre cas vous désirez vous connecter au server : irc.irchighway.net <br>
Aprés cette étape franchie,vous arriverez sur cette fenêtre :
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/06.jpg">
</p>
<p align="justify">
Aprés, dans fenêtre il vous faudrat vous connecter au channel désiré. Pour cela il vous suffit de taper la commande comme ci-dessous.
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/07.jpg">
</p>
<p align="justify">
Vous allez alors vous retrouver sur le channel tel :
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/08.jpg">
</p>
<p align="justify">
Afin de pouvoir télécharger les chapitres disponible sur le channel vous allez sur la page web qui liste <a href="http://null.myshelter.net" targer="_blank">les bots</a> qui sont disponible dans le channel. Dans notre cas ,nous apercevons que le chapitre 357 viens juste d'être sorti, donc nous choisissons l'une des commande présente sur le site :
par exemple : /msg Neverwhere xdcc send #1465
Cette commande signifie que je veux que le bot nommé <b>Neverwhere</b> m'envoie le pack 1465 qui correspond bien au chapitre 357 de one piece comme le montre l'image ci-desous.
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/13.jpg">
</p>
<p align="justify">
Voici une image montrant comment utiliser cette ligne de commande (dans le channel de la team)
</p>
<p align="center">
<img src="http://eastblue.net/picture/download/tutorial/irc/10.jpg">
</p>
<p align="justify">
Vous remarquerez que j'ai télécharger depuis un bot différent de l'exemple mais cela reste la même méthode.Une fois la commande lancé il vous downloadera dans le répertoire <b>download</b> de votre répertoire mIrc le chapitre.zip
<br><br>
ps:
lorsque vous faites votre copier coller ,faites bien attention à ce que le slash <b>/</b> se trouve être la première lettre(ne laissez pas d'espace sinon mirc n'interpretera pas la commande et vous passerez pour un boulet ^_^)
</p>
