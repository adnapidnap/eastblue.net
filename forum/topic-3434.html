Ah j'ai ces trophées. Je parie que tout le monde va me gueuler dessus mais pour avoir ces trophées, la seule solution c'est l'action replay.
Tu prends l'action replay Max pour GameCube (codejunkies), ca coute dans les 50€ environ et dans le cd t'as les codes de smash bros. Tu fais le code pour avoir tous les trophées et ces 2 la seront dedans. Probleme quand tu fais ce code tu as tous les trophées 999 fois. (Pas bien de tricher mais la y'a pas d'autre moyen))
Pour le home run contest mon maximum, c'est 1200m avec Ganondorf mais y'a beaucoup d'entrainement derrière. Le principal c'est d'avoir 450m je crois pour avoir un trophée ou un stage supp., si tu veux faire + c'est pour battre ton record mais ca n'apporte rien.
Sinon avec le même action replay tu peux avoir du temps infini dans le home run (au lieu de 10 sec) alors tu tape le sac autant que tu veux avant de l'envoyer tu fais 10000m a l'aise mais bon c'est debile, trop facile.
